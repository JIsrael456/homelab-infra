# Fase 01 - Infraestrutura de Rede

## Objetivo

Planejar e configurar a infraestrutura de rede utilizada pelo ambiente virtual da JI Tech Solutions, estabelecendo uma rede interna para comunicação entre servidores e estações de trabalho.

## Tecnologias

- VirtualBox
- Rede Host-Only
- NAT
- IPv4
- Subnetting
- DNS
- TCP/IP
- Ping
- NSLookup

- [x] Definir arquitetura da rede

- [x] Definir faixa de IPs
- [x] Configurar IP do servidor
- [x] Configurar IP do cliente
- [x] Definir servidor DNS
- [x] Configurar comunicação entre máquinas
- [x] Testar conectividade
- [x] Testar resolução de nomes
- [x] Documentar topologia
- [ ] Configurar DHCP
## Resultado esperado

Toda a infraestrutura será capaz de se comunicar através da rede interna da empresa.
